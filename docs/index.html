Установка занимает пару минут и не требует прав администратора.

  1. Скачай установщикКнопка справа ведёт на последний релиз — файл ViLauncher_0.5.0_x64-setup.exe.
  2. Запусти и установиЛаунчер ставится в профиль пользователя. Если в системе нет WebView2, он подтянется автоматически.
  3. Введи ник и нажми «Установить»Лаунчер сам скачает нужную Java, Minecraft и моды выбранного сервера. Дальше — «Играть».

Windows показывает предупреждение SmartScreen?

Установщик не подписан платным сертификатом Authenticode, поэтому при первом запуске Windows может написать «Система Windows защитила ваш компьютер». Это нормально для независимых проектов: нажми «Подробнее» → «Выполнить в любом случае». Исходный код открыт, а обновления самого лаунчера подписаны ключом проекта и проверяются перед установкой.

Что умеет лаунчер

  • ⚙

    Нативное ядро Rust + Tauri 2

    Лёгкий и быстрый: без Electron и тяжёлого браузера внутри. Мало памяти, быстрый старт, надёжная загрузка файлов.

  • 🗂

    Несколько серверов, у каждого свой instance

    У каждого сервера отдельный клиент: свои моды, настройки и версия Minecraft. Серверы не мешают друг другу.

  • ⬆

    Автообновление лаунчера

    Новые версии приходят сами. Обновления подписаны ключом проекта, лаунчер проверяет подпись перед установкой.

  • 🎛

    Настройки Minecraft и модов

    FOV, дальность прорисовки, звук, управление и конфиги модов — прямо в лаунчере, с проверкой и откатом к значениям по умолчанию.

  • 👤

    Вход по нику

    Аккаунт Microsoft не обязателен: достаточно ника. Один ник на все серверы лаунчера.

  • ⚡

    Умная загрузка модов

    Скачиваются только нужные файлы: лаунчер сверяет контрольные суммы и докачивает лишь изменившееся, а не весь модпак.
