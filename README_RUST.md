# ViLauncher — Rust-версия (v0.5.0)

Лаунчер на **Tauri 2 + Rust**, интерфейс — обычный JavaScript. Electron не нужен.
**Сборка с нуля, ключи подписи, релизы, включение серверов — в [BUILD.md](BUILD.md).**

```
crates/vilauncher-core/       ядро (без GUI): загрузка, Java, установка, серверы, instance'ы… — тесты: cargo test
tools/vilauncher-manifest/    программа для манифестов (хеши) → vilauncher-manifest.exe
src-tauri/                    Tauri: команды, трей, настройки, обновления (tauri-plugin-updater)
src/renderer/                 интерфейс; tauri-bridge.src.js → (esbuild) vendor/bridge.js
scripts/                      build-frontend.mjs (мост + шрифты), check-config.mjs (проверка безопасности)
tests/ui/                     тесты интерфейса (jsdom)
servers.json                  список серверов (корень репозитория, скачивается лаунчером)
legacy/                       старый Python-обновлятор и Electron-код — не используются, только для истории
.github/workflows/build.yml   тесты + релизная сборка с подписью обновлений
```

## Серверы и instance'ы
Четыре сервера описаны в `servers.json` (лаунчер скачивает его при запуске, кэширует; без сети — кэш, затем встроенная копия):

| Сервер | Minecraft | Тип | Сейчас |
|---|---|---|---|
| **Create** (+ Aeronautics) | 1.21.1 · NeoForge | modded | **активен** |
| Колонизация | 1.20.1 · Forge | modded | неактивен («Скоро») |
| Заражение | 1.21.1 · NeoForge | modded | неактивен («Скоро») |
| Ваниль · по подписке | всегда последняя версия | vanilla (без модов) | неактивен |

* **`active`** — единственный переключатель доступности. Неактивные карточки видны, но приглушены, у них бейдж «Скоро»,
  кнопка «Играть» заблокирована, а **бэкенд тоже отказывает** (синк, установка, запуск, сброс настроек) — обойти блокировку
  из интерфейса нельзя. Включить сервер = `"active": true` + `address` в `servers.json`, без правки кода (BUILD.md, раздел 10).
* **Instance'ы:** у каждого сервера свой клиент `.mc-launcher\instances\<instanceId>\` (моды, config, options.txt,
  launch.json, версия модов). Два сервера на 1.21.1 (Create и Заражение) — разные instance'ы и разные модпаки.
  Общие для всех: ник, `runtime\` (Java), `shared\` (шейдеры/ресурспаки). Клиентский прогресс лаунчер никогда не чистит.
* **Java по версии:** 1.20.1 → Java 17, 1.21.x и актуальная vanilla → Java 21 (берётся из данных Mojang). `runtime\java17`
  и `runtime\java21` живут рядом, уже установленная переиспользуется всеми instance'ами.
* **Vanilla:** установка клиента Mojang без загрузчика; `latest` определяется по манифесту Mojang (при выходе новой версии
  лаунчер просит обновить клиент).
* **Один ник на все серверы**, offline-режим, без Microsoft-аккаунта (Microsoft-вход остался в ядре как необязательный
  и в интерфейсе не используется).
* **Миграция:** прежний `.mc-launcher\client` при первом запуске переезжает в `instances\create` (переименование каталога,
  файлы целы).
* API окна: `listServers`, `selectServer`, `getInstanceStatus`, `refreshServers` (+ событие `servers-changed`); остальные
  методы `window.api` не менялись.

## Манифест из трёх файлов (на сервер)
`manifest.json` — моды/загрузчик (проверяется при старте, при «Играть» и раз в минуту во время игры) ·
`defaults.json` — настройки по умолчанию (скачиваются только если файла нет или по «Вернуть по умолчанию») ·
`blocklist.json` — «чёрный манифест» с ключевыми словами читов (игра закрывается с предупреждением).
Подробности и формат — ниже в разделе про программу манифеста и в BUILD.md.

## Обновления лаунчера и безопасность
* **Обновления:** `tauri-plugin-updater`, источник — `latest.json` в GitHub Releases (список `endpoints` в `tauri.conf.json`
  позволяет позже добавить свой сервер). Проверка при старте и вручную (Настройки → Проверить обновления), баннер с
  прогрессом, проверка подписи, установка, перезапуск. Подпись — бесплатный minisign/Ed25519 (`tauri signer`); приватный
  ключ только в `TAURI_SIGNING_PRIVATE_KEY` (GitHub Secrets), публичный — в `tauri.conf.json`. Платный Authenticode не используется.
* **CSP:** `default-src 'self'; script-src 'self'` (без `unsafe-eval` и inline-скриптов), `connect-src ipc:`, `object-src 'none'`,
  картинки только свои, `data:` и `cdn.modrinth.com`; шрифты локальные (без Google Fonts).
* **`withGlobalTauri: false`:** интерфейс общается с Rust через штатный `@tauri-apps/api`, собранный esbuild в `vendor/bridge.js`.
* **Права окна (capabilities)** сведены к минимуму: события listen/unlisten и управление окном (свернуть/развернуть/закрыть/перетащить).
  Никаких shell/fs/http-прав, `core:default` не используется.
* Хеши не ослаблены: моды, Java (SHA-256 Adoptium), installer загрузчика (SHA-1) и обновления лаунчера (подпись) проверяются.
  Во фронтенде нет `eval`/`new Function`; запуск процессов — только из Rust (игра через изолированную JRE).
* `npm run check:config` (и CI) проверяют всё перечисленное и согласованность моста с командами Rust.

## Программа `vilauncher-manifest`
Кладётся в папку с модами (корень репозитория или `servers\<имя>`) и запускается двойным кликом либо из консоли
(`--check`, `--dry-run`, `--mc`, `--loader`, `--client-revision`). Считает SHA-1 и подстраивает `manifest.json`,
`defaults.json`, `hashes.json`; находит свежий `*-installer.jar` и по его имени определяет версию Minecraft; версия растёт только
при реальных изменениях; показывает добавленные (+), удалённые (−) и изменённые (~) файлы; не принимает пустую `mods/`;
создаёт шаблон `blocklist.json`, если его нет. Готовый `.exe` — файл релиза или `cargo build --release -p vilauncher-manifest`.

## Раздел сервера в лаунчере
Главная → карточка выбранного сервера → панель «шейдеры, ресурспаки и настройки»: окно Modrinth (активные паки — по серверу),
редактор `options.txt` (FOV, дальность, FPS, звук, язык, управление…) и редактор `config/**` модов (проверка JSON/TOML,
сброс файла, «Вернуть ВСЕ настройки по умолчанию»). Во время игры сохранение блокируется.

## Три базовых модуля
Дельта-загрузка (`downloader.rs`, `sync.rs`), безопасное хранение секретов (`secure_store.rs`, keyring ОС) и изолированная Java
(`java_runtime.rs`) работают как раньше — теперь привязаны к instance'у и версии Java конкретного сервера.

## Что проверено, а что нет
**Проверено автоматически:** 120 Rust-тестов (дельта, повторы, отмена, хеши, traversal, keyring ОС, установка Minecraft+NeoForge и
vanilla/`latest` на mock-серверах, Java 17 рядом с 21, разбор и проверка `servers.json`, миграция `client/`, сторож модов/читов,
редактор настроек, программа манифеста), 12 тестов интерфейса (сетка серверов, блокировка неактивных, переключение,
баннер/прогресс обновления, редактор настроек, окно античита), проверка конфигурации безопасности, `cargo check` всего workspace
вместе с Tauri-слоем, сборка бандла моста (без `eval`), генерация ключей и подпись через `tauri signer`.
**Не проверено** (нет Windows/WebView2/интернета на стенде): сборка NSIS-установщика и публикация релиза в GitHub Actions,
реальное скачивание и установка обновления плагином, внешний вид в WebView2, трей, диалог выбора скина, живые Mojang/Modrinth/
Discord/Adoptium, настоящий NeoForge installer. Моды в репозитории пока под 1.20.1 — до выпуска замени их на версии под 1.21.1.
